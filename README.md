# 关系洞察 Studio

一个面向企业分析与专业汇报的关系可视化交互 Demo。当前项目使用完全合成的新能源产业数据，展示从多源证据到可复现视觉场景的完整工作流。

## Demo 能力

- 18 个虚构实体、32 条关系、15 份合成来源与 4 个叙事镜头
- 同一份图数据在分析 3D 与汇报 2D 之间切换
- 力导向、径向、层级三种布局；节点拖动与位置固定
- 主体、关系图层与实体搜索筛选
- 边级证据、来源定位、权限遮罩和人工核验
- 本地 CSV / JSON 导入，文件不会上传服务器
- PNG、SVG 与完整项目 JSON 导出
- Scene 保存与确定性演示流程

本版本是 Studio interaction demo，适合展示产品形态与核心工作流；它不代表 GPU 百万级大图的生产性能。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```
