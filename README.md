# 关系星图

一个可直接体验的中文人物关系可视化原型：粘贴小说、梗概或剧本片段，在本地识别人名与常见关系，并生成可旋转、缩放、拖动节点的 3D 网络。

## 当前能力

- 两组可一键载入的中文故事样例
- 亲属、友好、冲突、隐性关系分类
- 关系方向、原文证据与置信度
- 人物节点独立拖动和视角旋转缩放
- PNG 图片与 JSON 数据导出
- 移动端适配

演示版使用浏览器内的轻量规则解析，不上传文本，也不依赖 API Key。正式产品可将解析层替换为结构化大模型抽取与长文本 GraphRAG 管线。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```
